# Layza Portfolio

Portfolio profissional desenvolvido com React, Vite, TailwindCSS e Framer Motion para apresentar projetos web, desenvolvimento e branding pessoal em uma experiencia dark futurista.

## Stack

- React 19
- Vite
- TailwindCSS
- Framer Motion
- Lucide React

## Estrutura

```text
/
  src/
    assets/
    components/
    data/
    pages/
    styles/
```

## Como rodar

```bash
npm install
npm run dev
```

## Build de producao

```bash
npm run build
npm run preview
```

## Personalizacao

- Edite os projetos em `src/data/projects.js`
- Edite os dados pessoais em `src/data/profile.js`

## Recursos incluidos

- Hero com troca automatica de idioma no titulo
- Cards animados para projetos
- Secao sobre mim com posicionamento profissional
- Secao de contato moderna e responsiva
- Layout dark com glow neon e atmosfera tech
